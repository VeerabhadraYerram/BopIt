Let’s get BopIt connected.

Run npm run setup in the project folder. Then click below and approve the connection on the local page that opens. No pairing code to copy.

Once connected, return to your video, pause, click the BopIt toolbar icon, then Explore this moment. Results stay on that page.

Manual connection / troubleshooting

Open the local setup page and copy its pairing code.

Your Gemini API key belongs in the server’s .env file, never here. Each frame is previewed before upload.
